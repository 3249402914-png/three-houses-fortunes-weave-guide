# 风花雪月与万缕千丝攻略

《火焰纹章 风花雪月》与《火焰纹章 万缕千丝》的非官方中文攻略，提供网页版与安卓离线应用。

两个专区已合并到同一个页面。左侧按钮直接切换游戏，不跳转 HTML、不刷新整页；手机在导航菜单内切换。两边的周目记录独立保存，返回专区时恢复上次页面和滚动位置。

- 风花雪月：柔和灰绿，保留既有攻略。
- 万缕千丝：日间浅蓝灰，夜间深蓝灰与暗紫。统一入口 `dist/index.html#weave/home`；旧 `weave.html` 链接自动转入。
- 万缕千丝第一部收录 50 位角色、四路线招募对照、支援／名声检查、培养建议、个人技能等级、个人成长与 58 种职业加成、44 人的选录礼物、9 个限时外传。序章和后续篇章招募单独折叠。
- 两游戏分别保存计划，JSON 备份分别导入。主题偏好全站共用。

新增功能已通过数据及 DOM 模拟测试。此次浏览器工具被 URL 安全策略拦截，尚未完成新增专区的真实浏览器画面／尺寸检查；旧版浏览器验证记录仅代表旧版。

中文静态攻略工具，无 npm 依赖。覆盖 40 位可玩角色、4 条主线、DLC 灰狼与特殊加入角色。

默认夜间模式：深灰与低饱和绿。右上角切换日间 / 夜间，选择在刷新后保留。日间主题也采用柔和灰绿底色。

## 使用

双击 `打开攻略.cmd`，或打开 `dist/index.html`。推荐 HTTP 模式：在项目目录运行 `node server.mjs`，访问 http://127.0.0.1:5186/ 。服务器仅绑定本机。

`打开攻略.cmd` 现在会检查本地服务：已启动时直接打开，未启动时用 Node 隐藏启动服务；没有 Node 时仍可打开离线 HTML。电脑重启后需要再次双击入口，本地服务不注册为开机后台程序。

导航菜单新增全站搜索、全部职业、培养进度、精通与技能、装备与骑士团。搜索支持当前游戏的中英文名称；正文中带点状下划线的名称可直接打开详情，返回按钮回到原攻略。培养进度与精通记录和周目一起导出。资料来源列表显示完整网址。

风花雪月职业表收录 52 条可培养职业记录；装备资料表包含强化、损坏与敌方特殊版本，不代表所有条目都能获得。万缕千丝的 58 条职业只有名称与成长表得到核实，认证条件和精通效果仍待确认；骑士团也没有可靠完整逐团数值表，界面已明确标注。

在右上角设置路线、章节、主角性别、难度和 DLC。角色状态会随设置改变；设置只影响攻略提示，不会修改游戏存档。

- 角色图鉴：姓名、英文名、定位、学级筛选，收藏到周目计划。
- 挖角指南：属性 / 技能要求、支援折扣计算、性别与路线限制。
- 角色养成：每位角色建议、转职路线、职业精通、个人成长率、法术与技能适性。
- 剧情路线：4 条主线，分支触发与离队提醒默认折叠。
- 好感与失物：中英文礼物 / 失物反查、偏好茶和选录茶会话题；完整英文助手链接。
- 月历与外传：学院篇 12 个月的重点提示，选录重要外传与奖励条件。
- 我的周目：收藏、清单、随手记、JSON 导入 / 导出。

计划保存于当前浏览器。跨浏览器、跨设备需导出 / 导入；隐私模式或禁用存储时请导出备份。

## 验证

`node tests/core.test.cjs` 校验风花雪月。`node tests/weave.test.cjs` 校验万缕千丝数据、图片、条件计算与跨游戏备份隔离。

DOM 测试单独使用 jsdom，网页本身不需要运行依赖。通过 `pnpm --dir .sites/test-runtime add jsdom` 安装测试库后运行 `node tests/weave-dom.test.cjs`。它检查页面脚本与交互，不验证像素布局。

`node tests/single-page.test.cjs` 检查反复游戏切换时仍为同一个文档、全局事件清理、独立记录、页面与滚动恢复、主题、弹窗、浏览器后退及深链接。

旧版真实浏览器布局检查覆盖 320×568 至 3440×1440 等尺寸。当前合并版受浏览器工具访问策略限制，未重新进行像素布局验收。详细记录见 `QA.md`。

## 资料

见网页「资料来源与说明」及 `RESOURCE-README.md`。规则参考公开资料，培养路径为独立整理建议。中文物品名为对照译名，保留英文原名供不同汉化版本核对。

重点外传选录不等同于全章节逐关 walkthrough，完整外传条件有来源入口。没有复制完整攻略文章。

## 文件

- `dist/data.js`：角色、路线、培养建议与月历。
- `dist/extras.js`：角色成长率、法术、礼物、失物、技能适性与茶会事实表。
- `dist/core.js`：邀请窗口与门槛计算。
- `dist/app.js`、`dist/style.css`：交互与响应式页面。
- `site-source/`：两款游戏的页面模板；修改模板或游戏脚本后运行 `node prepare-single-page.cjs`，生成统一 HTML 与作用域隔离的游戏脚本。
- `dist/site-router.js`：同页路由、切换、返回与事件生命周期；网页无需额外框架或运行时构建。
- `dist/assets/`：本地素材，不依赖远程热链。
- `fetch-resources.ps1`、`fetch-character-data.ps1`、`prepare-data.cjs`：资料整理脚本（网页运行不需要）。
